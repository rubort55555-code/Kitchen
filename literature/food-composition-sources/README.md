# Базы состава продуктов разных стран — реестр и измеренный объём

Зачем: приложению нужны данные о железе, кальции, витамине C, фитатах, полифенолах по **десяткам тысяч** продуктов, а не по 2 894 позициям собственного справочника. Названия всех продуктов мира вручную не перечислить, поэтому используем три приёма: (1) национальные базы состава как источник данных; (2) классификацию **по категориям, составу и тегам**, а не по названию (`src/lib/iron.ts`); (3) поиск товара по штрихкоду в Open Food Facts (калорийность, железо, кальций, витамин C, категории и состав приходят с упаковки).

Числа ниже **измерены** в этой сессии скачиванием или запросом к API, кроме явно помеченных «не проверено».

## Как это связано с русским интерфейсом
Базы других стран названы на своих языках. Для приложения важны **группы и свойства**, а не перевод тысяч названий: название нужно только там, где человек выбирает продукт руками (справочник приложения) — там русские названия и разметка по железу уже есть. Для остального (штрихкоды, чеки) работают категории OFF и состав с упаковки. Прямой перенос иностранных названий в русский справочник без ручной проверки не делаем: машинный перевод ошибается на редких продуктах.

## Первый результат масштабирования
Разметка по группам USDA без перечисления названий покрывает **81%** всех железосодержащих продуктов (≥ 1 мг/100 г) в SR Legacy: 3 619 из 4 462. Остальные 843 — смешанные группы (готовые блюда, детское питание, снеки, фастфуд, напитки), для них нужна классификация по составу (так делает `foodIronOfProduct` для товаров по штрихкоду).

## CoFID (Великобритания): железосодержащие продукты по кодам групп CoFID
Группы (по таблице «1.4 Inorganics»): DR — 175, MAE — 97, MR — 88, MAC — 88, DG — 66, DB — 62, H — 56, FA — 47, GA — 41, AM — 41, AF — 38, MG — 37 продуктов с железом ≥ 1 мг/100 г. Расшифровка кодов групп CoFID (DR, MAE и др.) в этой сессии не разбиралась.
