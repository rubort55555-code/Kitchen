# Химический состав российских пищевых продуктов

**Скурихин И. М., Тутельян В. А. (ред.). Химический состав российских пищевых продуктов: справочник. — М.: ДеЛи принт, 2002. Институт питания РАМН.** 237 страниц, скан с распознанным текстовым слоем.

Источник: ссылка владельца проекта на ресурс электронной образовательной среды вуза (`eos.togudv.ru`, учебная программа владельца). Из облачного окружения сайт соединение обрывает, поэтому файл прислан владельцем проекта частями (страницы 1–100, 100–200, 200–237, архив `ilovepdf_split-range.zip`). Страницы 100 и 200 в частях повторяются; тексты дублей совпали, дубли убраны, части склеены без пересжатия (pypdf) в один файл.

## Разбор таблиц (`chunks/tables/`) — `tools/parse-russian-tables.py`

Из пар страниц таблиц 1–12 (стр. 25–193; слева код, название, порция и вещества, справа минералы и витамины) достаются значения на 100 г. Скан сдвигает колонки от страницы к странице, а набор колонок зависит от таблицы (жиры: 9 слева и 15 справа, напитки: 17 справа), поэтому схема выбирается по данным страницы, а значения относятся к колонкам по их положению: положения колонок берутся из строк этой же страницы, в которых число значений сошлось с числом колонок. Пустая клетка в оригинале остаётся пустой; цифры не угадываются.

Результат: **принято 1 002 строки из 1 074 найденных** (`foods_parsed.jsonl`), отброшено 72 (`rejected.jsonl`, у каждой причина). Единицы и порядок колонок — `_report.json`.

**Ручная доработка (11.11.2026).** У 106 строк текстовый слой не прочитал основное значение (белки, вода, жиры, углеводы, зола или энергию) или значение не сошлось со второй порцией. Эти строки прочитаны вручную по вырезкам скана (300 значений: `tools/russia-manual-corrections.json`, ключ — страница PDF и код) и подставлены поверх разобранных; после этого строки прошли те же проверки. Все 106 приняты: сумма компонентов у каждой 100 ± 1,5 г, энергия сходится с БЖУ у всех, кроме двух (курага 9.1.1.3 и какаовелла 10.11.5 — собственные коэффициенты справочника, помечены `flags`). При чтении выяснилось, что в «автоматических» значениях этих строк тоже есть ошибки скана (например, железо 5 вместо 0,5 у салата 8.1.1.5, вода 75,0 вместо 75,4 у картофеля 8.1.4.14), и что проверка по второй порции принимала строку «% суточной потребности» за вторую порцию (пряники, пирожные); последнее исправлено в парсере.

Что проверяется у каждой строки:
- вода, белки, жиры, углеводы, зола и энергия на месте, вода + белки + жиры + углеводы + клетчатка + кислоты + зола = 100 ± 1,5 г (у 985 из 1 002 отклонение не больше 0,5 г);
- **независимая сверка по второй порции:** у 695 строк есть вторая строка порции (200 г и т. п.), где значения равны первой строке × порция/100. Сошлись 17 966 значений из 18 067; 101 значение (0,56%) не сошлось с допуском на округление, оно **не берётся** (клетка пустая, в записи `check_portion2.suspect`); исключение — значения, прочитанные вручную;
- энергия, не сходящаяся с БЖУ (± 12% или ± 10 ккал), у 22 строк (печень, почки, паштет, горошек, курага…): это либо собственные коэффициенты справочника, либо ошибка скана. Строка принята с пометкой `flags`; энергию из неё не использовать.

Пометки в записях: `method` («строго» — число значений совпало с числом колонок и положение подтверждено, «по колонкам» — часть клеток пуста или лишний знак скана отброшен), `unreadable` (49 строк: значение справа не читается — клетка пуста), `dropped_marks` (отброшены лишние знаки), `pair` (10 строк: код справа не распознан, строка сопоставлена по порядку), `manual` (106 строк: список колонок, прочитанных вручную), `check_portion2`.

**Выборочная проверка по скану** (вслепую, строки вырезаны из PDF и сверены со значениями):
- 8 строк до проверки по второй порции: 7 верны, в одной ошибки скана (вода 59,0 вместо 59,8, магний 71 вместо 27, железо 10 вместо 1,0). Эту ошибку теперь ловит проверка по второй порции;
- 10 строк **без второй порции** (то есть без независимой сверки): из 270 значений верны 267, одно неверно (натрий 1,0 вместо 17 у сушёных абрикосов), два пусты (потеряны сканом). Оценка для 307 строк без второй порции: примерно одно неверное значение на 250, то есть 90% строк целиком верны. У 14 из них значения прочитаны вручную.
- Ранее принятые первой версией разбора пять строк (Вобла, Галеты, Компот и др.) оказались сдвинутыми на колонку; сверкой по скану подтверждено, что новая версия их читает верно. Строки макарон и молока сверены по скану дважды.

Остаток отброшенных (72):

| Причина | Строк |
|---|---|
| страницы 81 (килька, в строках нет одной колонки) и 187 (пиво, вино: 8–9 значений слева): нет строк для калибровки колонок | 26 |
| код справа не распознан и число строк слева и справа разное | 18 |
| сумма компонентов не 100 ± 1,5 г (скан исказил число) | 18 |
| значения на порцию 50–80 г (бутерброды), не на 100 г | 5 |
| порция в строке не прочиталась | 5 |

Их можно добрать только вручную по скану (так же, как 106 выше); страницы и коды — в `rejected.jsonl`. **Не разобраны совсем:** строки порций 150–310 г и «% суточной потребности» (они используются только для проверки), приложения, указатель. Коды в книге уникальны, но в OCR возможны повторы — они помечены `dup_code`.

## Права

Справочник охраняется авторским правом (издание 2002 г.). Владелец проекта разрешил использовать файл («по нему учился», ссылка из учебной программы). Если репозиторий публичный, `source/` и `chunks/book/*.pdf` доступны всем — решите, оставлять ли их в репозитории (текст и разобранные значения можно оставить отдельно).
