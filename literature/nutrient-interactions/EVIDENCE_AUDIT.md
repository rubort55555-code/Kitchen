# Вес доказательств

Правило: чем строже дизайн и крупнее выборка, тем больше доверия (A — регуляторные заключения, мета-анализы РКИ и РКИ с n ≥ 1000; B — РКИ n ≥ 100, большие наблюдательные n ≥ 10 000; C — малые испытания, обзоры; D — механизмы). Реализация: `levelOf` в `src/lib/interactions.ts`; в приложении у каждой подсказки показана надёжность и уровень каждого источника.

## Что изменилось после пересмотра
- **Витамин C и железо.** Мета-анализы РКИ: Deng 2024 (10 РКИ, n = 1782) — гемоглобин +0,14 г/дл, клинически малозначимо; Loganathan 2023 (n = 905) — значимой разницы нет; Nyakundi 2026 (15 РКИ, n = 1381) — ферритин и гемоглобин растут, всасывание железа почти не меняется. Изотопные работы (Heffernan 2017, n = 315) показывают рост всасывания в одном приёме пищи. Формулировка подсказки смягчена: помогает в приёме пищи, на запасы за месяцы эффект небольшой.
- **Кофеин и минералы.** Порог подсказки поднят с 300 до 400 мг; пояснено, что в крупных работах вреда костям при привычном количестве не видно. Источники по выведению минералов (1980–90-е, малые выборки) остаются уровнем C. Крупный поиск по этой теме ещё не завершён (упёрлись в лимит запросов).
- Кальций/фитаты/цинк: опираются на обзоры и малые изотопные работы (C); крупных РКИ с n ≥ 1000 не найдено — требует поиска.
