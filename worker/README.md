# Приёмник сообщений об ошибках

Маленький сервер на бесплатном Cloudflare Workers. Принимает сообщения из приложения «Кухня»
(кнопка «Ещё → Сообщить об ошибке») и превращает их в задачи (issues) в этом репозитории.

- **Анонимно:** приёмник не читает и не сохраняет адрес подключения, не выдаёт идентификаторов, журналы выключены.
- **Голос:** запись переводится в текст бесплатной моделью Whisper (Cloudflare Workers AI) и нигде не сохраняется.
- **Вложения:** картинки, PDF и текстовые файлы (до 5 штук, каждый до 5 МБ) кладутся в ветку `feedback-data`
  и показываются в задаче. Внимание: репозиторий открытый, значит, их видит любой.

## Настройка (один раз, около 10 минут)

1. **Cloudflare.** Заведите бесплатный аккаунт на cloudflare.com. На странице Workers & Pages скопируйте *Account ID*.
   В «My Profile → API Tokens» создайте токен по шаблону *Edit Cloudflare Workers* и скопируйте его.
2. **Бот GitHub.** На GitHub откройте Settings → Developer settings → Personal access tokens → Fine-grained tokens.
   Создайте токен только для репозитория `Kitchen` с правами *Issues: Read and write* и *Contents: Read and write*.
   Лучше создать его с отдельного аккаунта-«бота», тогда задачи будут от его имени.
3. **Секреты репозитория.** В репозитории: Settings → Secrets and variables → Actions → New repository secret. Добавьте три:
   `CLOUDFLARE_API_TOKEN`, `CLOUDFLARE_ACCOUNT_ID`, `FEEDBACK_GITHUB_TOKEN` (токен бота).
4. **Развёртывание.** Вкладка Actions → «Приём сообщений» → Run workflow. Через минуту сервер заработает.
5. **Адрес.** Выкладка пишет адрес в журнал (`https://kitchen-feedback.ВАШ-ПОДДОМЕН.workers.dev`). Он уже прописан
   в `src/lib/feedback.ts` (`DEFAULT_URL`). Если адрес поменяется, измените эту строку или задайте при сборке переменную
   `FEEDBACK_URL` (GitHub: Settings → Secrets and variables → Actions → Variables).

## Проверка

Откройте адрес в браузере: должно быть написано `kitchen-feedback ok`. Затем отправьте тестовое сообщение
из приложения: в репозитории появится задача с меткой «из приложения».

## Лимиты

Не больше 6 запросов в минуту с одного подключения; текст до 5000 знаков; запись голоса до 2 минут.
Бесплатный тариф Workers AI имеет суточный лимит распознавания; если он исчерпан, голос временно не работает,
а текстовые сообщения продолжают приходить.
