# Сущности (Entity) — центр приложения

Здесь «предметы» приложения и правила про них, которые верны всегда, на любом экране:
нельзя списать больше, чем есть; закончившийся продукт исчезает; после вскрытия срок короче.

Договорённости:

1. **Ни от чего не зависят.** Файлы этой папки импортируют только друг друга. Нельзя: React, `src/lib/db.ts`,
   `src/lib/store.ts`, Capacitor, `fetch`, `localStorage`.
2. **Карточка + инструкция.** Сущность — обычные данные (тип), правила — чистые функции рядом:
   `takeProduct(milk, 200)` возвращает новую карточку и не меняет старую. Карточки без преобразований
   кладутся в базу, в копию данных и в React.
3. **Время и номера — снаружи.** Правила сами не смотрят на часы и не придумывают id: `today`, `now`, `id`
   приходят аргументами. Одинаковый вход — всегда одинаковый результат, проверки не зависят от даты.

Проверки: `tests/domain-*.test.ts`.
